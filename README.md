# 投上岸

> 批量投递自动化助手 —— 桌面客户端（Windows）＋ 浏览器插件，帮助你把简历一键投递到主流招聘平台。

「投上岸」由两部分组成：

- **桌面客户端 `投上岸.exe`**：本地运行的后端服务（默认 `http://localhost:5100`），负责调度与数据处理。
- **浏览器插件 `投上岸助手`（Chrome 扩展，v1.0.4）**：在招聘网站页面中自动填写并投递，与桌面客户端通过本地接口通信。

---

## ✨ 功能特性

- 支持多个主流招聘平台批量投递：
  - BOSS 直聘（zhipin.com）
  - 猎聘（liepin.com）
  - 智联招聘（zhaopin.com）
  - 前程无忧 51Job（51job.com）
- 桌面客户端 + 浏览器插件协同工作，自动化完成页面操作。
- 内置启动脚本，双击即可运行。
- 投递结果输出到 `outputs/` 目录，便于查看与复盘。

## 📁 目录结构


## 🚀 安装与使用

### 1. 运行桌面客户端

- 解压本项目到任意目录。
- 双击 **`启动投上岸.bat`**（或直接运行 `投上岸.exe`）。
- 启动后桌面客户端会在本地 `http://localhost:5100` 提供后端面板。

> 系统要求：Windows 操作系统。首次运行若被系统拦截，请在系统弹窗中选择「仍要运行」。

### 2. 安装浏览器插件

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 右上角开启「开发者模式（Developer mode）」。
3. 点击「加载已解压的扩展程序（Load unpacked）」，选择本项目中的 `extension/` 文件夹。
4. 插件「投上岸助手」即会出现在扩展列表中，点击图标可打开操作面板。

### 3. 开始投递

- 在浏览器中登录对应招聘平台账号。
- 通过插件面板启动自动投递，桌面客户端负责后台调度。
- 投递记录与结果保存在 `outputs/` 目录。
